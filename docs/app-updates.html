Garage Log updates

Proposal: the app checks GitHub for a newer version, tells you, downloads it when you tap Update, and hands it to Android's install screen. No more opening the download link in the browser. Sample screens below; nothing is built yet.

The options

Every way of installing an app from outside the Play Store ends at Android's "Do you want to update this app?" screen. Android requires that tap; no app can skip it the first time. The choice is about who notices the new version and fetches it.

How the in-app check works

  • Where it looks: GitHub's latest release for motomech/garage-log (the same one the download link uses). The repo is public, so no account or key. Each release is tagged 0.1.N, and N is the app's version code, so "newer" is a plain number compare.
  • When: when the app opens (at most every 6 hours) and once a day in the background with the reminder check. One small web request.
  • What's new: the release notes list the merged pull requests, so the card can say what changed. That is a one-line change to the build.
  • Install: the app downloads the APK into its own storage, checks it is signed with the same key, then opens Android's install screen. Data is kept, as with the browser download today.
  • Trips: installing closes the app, so the Update button waits while a trip is in progress.
  • Turn off: a "Check every day" switch. "Check now" works either way.
  • Maybe zero taps later: on Android 12 and newer, once Garage Log has installed its own update, Android may let later updates go through without asking. We would try it on your phone; if Android still asks, it stays one tap.

Until it's built

Obtainium works now with no changes: install it from github.com/ImranR98/Obtainium, tap Add App, paste github.com/motomech/garage-log. After the in-app check ships, Obtainium can be removed.
