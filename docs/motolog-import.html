What's in the two files

Each file covers one vehicle. The top row holds the vehicle (name, make, model, year, displacement, plate, VIN), then the report name, the date range, the column headings and one row per entry, with a Total row at the bottom.

Questions for you

1. Do you use the Business / Private tags?68 of your 182 trips are tagged Business (642 mi). My suggestion: keep the tag on each trip and show business miles per year on the Costs tab, which is what you'd need for taxes or reimbursement. Rates and reimbursement amounts can wait. If you never use it, I'll drop the tags.
2. Do you have service, expense or parts records in MotoLog?These two files have none. If MotoLog has Service, Expenses or Parts reports, export one as Excel and send it, so the import can read those too.
3. Your other vehicles?Each file is one vehicle. Export the same reports for each vehicle; you can pick all of them in one go.
